# Assets Images

## Globee Logo
- Place your Globee logo image as `globee_logo.png` in this directory
- The logo will be used in the splash screen and throughout the app

## Required Images:
- `globee_logo.png` - Main logo for the app

## Image Guidelines:
- Use PNG format for logos with transparency
- Recommended size: 512x512px for logos
- Keep file sizes optimized for mobile apps
